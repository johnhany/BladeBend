内蒙古电网分为 **蒙西电网** 和 **蒙东电网** 两大独立运营主体，这是全国唯一的"一区两网"格局。两网的分界源于2009年国家电网接收原内蒙古电力集团东四盟市电网资产。

---

## 蒙东电网（国网内蒙古东部电力有限公司）

**隶属关系**：国家电网公司全资子公司（央企）  
**供电区域**：4个盟市

| 地区 | 类型 |
|------|------|
| **赤峰市** | 地级市 |
| **通辽市** | 地级市 |
| **兴安盟** | 盟 |
| **呼伦贝尔市** | 地级市 |

**关键信息**：国网蒙东电力成立于2009年6月，供电面积约47万平方公里，供电人口约1200万。 

---

## 蒙西电网（内蒙古电力（集团）有限责任公司）

**隶属关系**：内蒙古自治区直属国有独资特大型电网企业（地方国企），是全国唯一独立于国家电网、南方电网之外的省级电网企业  
**供电区域**：8个盟市

| 地区 | 类型 |
|------|------|
| **呼和浩特市** | 地级市（首府） |
| **包头市** | 地级市 |
| **鄂尔多斯市** | 地级市 |
| **乌兰察布市** | 地级市 |
| **锡林郭勒盟** | 盟 |
| **巴彦淖尔市** | 地级市 |
| **乌海市** | 地级市 |
| **阿拉善盟** | 盟 |

**关键信息**：蒙西电网供电区域约72万平方公里，承担着8个盟市工农牧业生产及城乡约1400万居民生活供电任务，同时向华北电网、陕西榆林和蒙古国提供跨省区、跨国境供电。
