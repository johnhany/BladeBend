## 1. 文档概述

### 1.1 项目背景
中国电力市场正处于深度市场化改革阶段。截至2026年，全国已有29个省级电网实现电力现货连续交易，省间现货市场转入正式运行，电价波动加剧，新能源全面入市。在这一背景下，亟需一个统一的可视化平台，将分散在全国各省的装机结构、电价水平和省间交易价格进行空间化呈现，辅助市场分析、投资决策与政策研究。

### 1.2 项目目标
构建一个以**自定义矢量地图**为核心的可视化网页应用，实现：
- **空间化呈现**：全国各省（含自治区、直辖市）的电力装机结构、电力价格及省间交易价格。
- **跨省通道可视化**：在地图上叠加主要特高压及跨省输电通道，直观展示电力资源跨区域配置格局。
- **数据时效性**：依托北极星电力网资讯爬取能力，实现数据的定期更新与展示。
- **交互探索**：支持用户按维度筛选、下钻、对比，快速定位关键信息。

### 1.3 目标用户
| 用户角色 | 核心诉求 | 使用场景 |
|---------|---------|---------|
| 电力行业分析师 | 快速掌握各省电源结构与价格水平，进行横向对比 | 日常市场监测、研报撰写 |
| 发电/售电企业决策者 | 识别高电价区域、评估跨省交易机会 | 市场开拓、交易策略制定 |
| 投资机构研究员 | 评估区域电力供需格局与新能源消纳空间 | 行业研究、标的筛选 |
| 政策研究人员 | 观察市场化改革进展与区域差异 | 政策效果评估 |

## 2. 术语与单位规范

### 2.1 术语表
| 术语 | 说明 |
|-----|------|
| **装机量** | 发电设备的额定装机容量 |
| **现货电价** | 电力现货市场中按实时供需形成的电价，通常以15分钟或1小时为周期出清 |
| **中长期电价** | 通过年度、月度、周度等中长期合约锁定的电价 |
| **省间交易价格** | 跨省跨区电力交易（含省间现货与中长期）的加权均价 |
| **特高压通道** | ±800kV直流或1000kV交流输电线路，承担大规模跨省电力输送 |
| **TopoJSON/GeoJSON** | 地理矢量数据格式，用于描述省份边界、城市点位等空间要素 |

### 2.2 单位规范（强制）

| 数据类型 | 统一单位 | 备注 |
|---------|---------|------|
| 装机量（各类电源及总装机） | **MW** 或 **GW** | 数据库存储统一为 **MW**；前端展示根据数值大小自动切换（<1000 用 MW，≥1000 用 GW） |
| 电力价格（现货/中长期/省间交易） | **元/MWh** | 避免使用 元/千瓦时，确保与电力行业惯例一致 |
| 交易电量 / 输送电量 / 用电量 | **MWh** 或 **GWh** | 数据库存储统一为 **MWh**；前端根据数值大小自动切换展示（<1,000,000 用 MWh，≥1,000,000 用 GWh） |
| 输送容量 | **MW** | 与装机量单位保持一致 |

## 3. 功能需求

### 3.1 地图可视化层（核心）

#### 3.1.1 底图渲染
- **数据来源**：使用开源地理矢量数据（Natural Earth 1:10m 文化矢量数据），自行处理中国领土合规性（台湾、南海诸岛完整呈现）。**不嵌入任何第三方地图 SDK**（如高德、百度、Mapbox）。
- **投影方式**：采用 Albers 等面积投影或等角横轴墨卡托投影，确保中国全域完整、无变形展示。
- **视觉风格**：
  - 背景：深色或低饱和度色系（如 `#0a1628` 或 `#1a1a2e`），突出数据图层。
  - 省份填充：根据当前选中指标进行分级设色（Choropleth），未选中指标时显示统一底色。
  - 省份边界：1px 细线，颜色与背景形成适度对比。
  - 海岸线与岛屿：清晰勾勒，南海诸岛以插图形式展示。

#### 3.1.2 省份交互
- **悬停（Hover）**：鼠标悬停至某省份时，该省份高亮（边框加粗/发光），并浮现 Tooltip，展示该省关键指标摘要（名称、总装机、当前选中电价）。
- **点击（Click）**：点击省份后，右侧（或底部）滑出/展开**省份详情面板**，展示该省完整数据与趋势。
- **多选对比**：支持 Ctrl/Shift + 点击多选省份，进入对比模式，面板切换为并列对比视图。

#### 3.1.3 城市点位
- **展示范围**：展示各省会城市及主要电力负荷中心（如深圳、苏州、鄂尔多斯等）。
- **视觉表达**：以圆点标记，大小可映射该城市用电量或负荷规模（可选）。
- **交互**：悬停显示城市名称及关键负荷数据。

#### 3.1.4 跨省输电通道
- **通道数据**：覆盖国家已建成及在建的主要特高压交直流线路，包括但不限于：
  - 直流：宁东-浙江、锡盟-泰州、扎鲁特-青州、糯扎渡-广东、藏粤直流、雅中-江西、白鹤滩-江苏/浙江 等。
  - 交流：1000kV 榆横-潍坊、锡盟-山东、淮南-南京-上海 等。
  - 区域互济：湖南-贵州、粤桂滇黔琼南方区域通道 等。
- **视觉表达**：
  - 以**曲线**连接起点与终点换流站/变电站，线宽映射通道输送容量。
  - 直流通道与交流通道使用不同线型（如实线 vs 虚线）或颜色区分。
  - 通道上可叠加**动态粒子流**（Particle Flow），方向表示潮流方向，密度/速度映射输送功率大小。
- **交互**：悬停通道显示通道名称、电压等级、额定容量、当前输送功率（如有数据）。

#### 3.1.5 自然地理要素（可选）
- **主要山脉**：秦岭、大兴安岭、横断山脉等，以浅灰色阴影或线描形式低调呈现。
- **主要河流**：长江、黄河、珠江等，以细曲线呈现。
- **目的**：辅助理解电源分布与地理禀赋的关系（如水电集中于西南、风电集中于三北）。

### 3.2 数据展示层

#### 3.2.1 装机量模块
| 指标 | 单位 | 可视化方式 |
|-----|------|-----------|
| 火电装机 | MW / GW | 堆叠柱状图 / 省份填充色 |
| 水电装机 | MW / GW | 堆叠柱状图 / 省份填充色 |
| 风电装机 | MW / GW | 堆叠柱状图 / 省份填充色 |
| 光伏装机 | MW / GW | 堆叠柱状图 / 省份填充色 |
| 核电装机 | MW / GW | 堆叠柱状图 / 省份填充色 |
| 其它装机 | MW / GW | 堆叠柱状图 / 省份填充色 |
| **总装机** | **MW / GW** | **主指标，默认以分级设色映射至省份填充** |

- **展示形态**：
  - **地图模式**：以总装机为默认着色指标，颜色深浅表示规模。
  - **详情面板**：以堆叠柱状图展示该省各类电源占比，支持切换为饼图/环形图。
  - **全国概览**：顶部或侧边栏展示全国总装机及各类电源占比的汇总卡片。

#### 3.2.2 电力价格模块
| 指标 | 单位 | 说明 |
|-----|------|------|
| 现货均价 | 元/MWh | 最近一个完整月的现货市场加权均价 |
| 中长期均价 | 元/MWh | 最近一个完整月的中长期合约加权均价 |
| 峰谷价差 | 元/MWh | 现货市场峰段与谷段价差 |
| 价格区间 | 元/MWh | 月度最高/最低现货价 |

- **展示形态**：
  - **地图模式**：支持切换以"现货均价"或"中长期均价"对省份进行分级设色。
  - **详情面板**：展示该省近6-12个月的现货与中长期价格走势折线图。
  - **异常标注**：对出现负电价或触及限价上限的省份，在地图上以特殊图标（如 ⚠️）标记。

#### 3.2.3 省间交易价格模块
| 指标 | 单位 | 说明 |
|-----|------|------|
| 送出均价 | 元/MWh | 该省作为送端时的省间交易加权均价 |
| 受入均价 | 元/MWh | 该省作为受端时的省间交易加权均价 |
| 交易电量 | MWh / GWh | 月度省间交易电量规模 |

- **展示形态**：
  - **地图模式**：在跨省通道上以色带或标注形式显示该通道的近期交易均价。
  - **详情面板**：展示该省主要的送电/受电通道列表及对应价格、电量。

### 3.3 交互与控制层

#### 3.3.1 全局控制栏
- **指标切换器**：下拉菜单或 Tab 切换，支持在"装机量 / 现货电价 / 中长期电价 / 省间交易"四大维度间切换。
- **时间选择器**：
  - 装机量：支持按年度/季度查看（历史回溯）。
  - 电价：支持按月度查看，默认展示最近完整月份。
- **图层开关**：独立的 Toggle 控制城市点位、输电通道、山脉河流的显隐。

#### 3.3.2 图例与比例尺
- 动态图例：根据当前选中指标自动更新分级色带及数值范围。
- 迷你比例尺：右下角展示，辅助空间尺度感知。

#### 3.3.3 搜索与定位
- 支持按省份名称、城市名称、通道名称搜索，自动定位并高亮目标。

#### 3.3.4 数据下钻
- 从全国视图 → 区域视图（如华北、华东）→ 省份视图，支持平滑缩放过渡。

## 4. 数据需求与处理流程

### 4.1 数据来源与更新策略

| 数据类型 | 来源 | 更新频率 | 备注 |
|---------|------|---------|------|
| 装机量 | 北极星电力网（通过 bjx.geekbit.org 索引 → 正文爬取 → LLM 解析） | 月度/季度 | 需多模态解析（文本、表格、图片中的图表） |
| 现货/中长期电价 | 北极星电力网（同上） | 月度 | 按月统计均价即可 |
| 省间交易价格 | 北极星电力网（同上） | 月度 | **仅依赖北极星，数据缺失属正常情况** |
| 输电通道 | 网络检索（用户提供检索结果） | 按工程投运更新 | 静态数据为主，见 4.3 节格式要求 |
| 地理底图 | Natural Earth 开源数据 | 一次性 | 自行处理合规性 |

#### 4.2.1 多模态解析详细说明

**阶段一：索引获取**
- 从 `https://bjx.geekbit.org/` 获取每日新闻列表，提取标题、URL、发布时间。
- 根据关键词过滤（如"装机"、"电价"、"现货"、"省间交易"、"特高压"等）筛选目标文章。

**阶段二：正文爬取**
- 访问筛选出的文章 URL，获取完整 HTML 正文。
- 同时下载正文中的所有图片（含图表、数据可视化图片），保存至本地。
- 对图片进行哈希去重，避免同一图表被多次解析。

**阶段三：内容解析（LLM 辅助）**

| 内容类型 | 处理方法 | LLM Prompt 方向 |
|---------|---------|----------------|
| **纯文本段落** | 正则提取数字+省份+单位，LLM 二次校验 | "从以下电力行业新闻中提取 [省份] 的 [指标] 数据。**功率统一单位为 MW，电价统一为元/MWh，电量统一为 MWh**。以 JSON 输出" |
| **HTML 表格** | 先解析为 DataFrame，LLM 识别表头映射 | "识别表格列含义，将数据映射到标准字段：province, thermal_mw, hydro_mw, wind_mw, pv_mw, nuclear_mw, other_mw, total_mw, spot_price_yuan_mwh, medium_long_price_yuan_mwh, trade_volume_mwh" |
| **图片中的表格** | OCR（如 PaddleOCR / Tesseract）提取文本 → LLM 结构化 | "以下是从图片中 OCR 提取的表格文本，请整理为标准表格格式。**注意：功率用 MW，电价用 元/MWh，电量用 MWh**" |
| **图片中的柱状图/折线图** | 图表解析（如 Chart-to-Text 或 LLM 视觉模型）提取数据点 | "分析以下电力数据图表，提取各省份/各月份的数值。**功率统一为 MW，电价统一为 元/MWh，电量统一为 MWh**。以 JSON 输出" |

**阶段四：数据清洗**
- **单位统一**：将所有功率转换为 **MW**，所有电价转换为 **元/MWh**，所有电量转换为 **MWh**。
- **省份标准化**：使用标准行政区划代码（如 GB/T 2260）或统一名称（如"内蒙古自治区"简化为"内蒙古"）。
- **时间标准化**：统一为 `YYYY-MM` 格式。
- **异常值处理**：设定合理阈值（如电价 >2000 元/MWh 或 <0 元/MWh 时标记待审核）。

### 4.3 跨省输电通道数据格式要求

用户将通过网络检索提供输电通道数据，为便于直接导入系统，请按以下 **JSON/GeoJSON 格式** 提供：

```json
{
  "channels": [
    {
      "id": "nindong-zhejiang",
      "name": "宁东-浙江±800kV特高压直流",
      "type": "DC",           
      "voltage_kv": 800,
      "capacity_mw": 8000,
      "start_point": {
        "name": "宁夏宁东换流站",
        "province": "宁夏",
        "city": "灵武",
        "lat": 38.1,
        "lng": 106.8
      },
      "end_point": {
        "name": "浙江绍兴换流站",
        "province": "浙江", 
        "city": "绍兴",
        "lat": 30.0,
        "lng": 120.6
      },
      "commissioning_date": "2016-09",
      "status": "operational",
      "notes": "宁夏送浙江"
    }
  ]
}
```

**字段说明**：
| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| `id` | string | 是 | 唯一标识，英文+数字 |
| `name` | string | 是 | 通道全称 |
| `type` | string | 是 | `DC`（直流）或 `AC`（交流） |
| `voltage_kv` | number | 是 | 额定电压，单位 kV |
| `capacity_mw` | number | 是 | 额定输送容量，单位 MW |
| `start_point` / `end_point` | object | 是 | 起点/终点信息，含经纬度 |
| `commissioning_date` | string | 否 | 投运日期，格式 `YYYY-MM` |
| `status` | string | 是 | `operational`（运行）/`under_construction`（在建）/`planned`（规划） |
| `notes` | string | 否 | 补充说明 |

## 5. 非功能需求

### 5.1 性能要求
- **首屏加载**：地图底图 + 初始数据在 3 秒内完成加载（常规网络环境下）。
- **交互响应**：悬停、点击、缩放等操作帧率不低于 30fps，无卡顿。
- **数据量**：支持全国 34 个省级行政区 × 12 个月 × 多指标的数据规模，前端渲染无压力。

### 5.2 兼容性
- **浏览器**：Chrome 90+、Firefox 88+、Edge 90+、Safari 14+。
- **分辨率**：适配 1920×1080 及以上桌面端，支持响应式布局（最低兼容 1366×768）。

### 5.3 可访问性
- 支持键盘导航（Tab 切换焦点、Enter 选中）。
- 色盲友好：避免仅依赖红绿色区分关键信息，提供图案/纹理辅助。

### 5.4 安全与合规
- **地图合规**：确保使用符合国家测绘法规的地理底图数据，台湾、南海诸岛等领土要素完整、准确。
- **数据安全**：本项目为个人使用，电价数据均为公开市场化数据，不涉及国家秘密。

## 6. 技术架构

### 6.1 部署环境

### 6.4 数据更新脚本
提供独立的 Python 脚本 `update_data.py`，功能如下：

```bash
# 使用示例
python update_data.py --mode full          # 全量更新（爬取索引 + 解析所有历史文章）
python update_data.py --mode incremental   # 增量更新（仅处理本月新增文章）
python update_data.py --mode price         # 仅更新电价数据
python update_data.py --mode capacity      # 仅更新装机量数据
python update_data.py --year 2026 --month 7  # 指定年月更新
```

**脚本输出**：
- 结构化 JSON/CSV 数据文件，存放于 `data/` 目录。
- 运行日志 `logs/update_YYYY-MM-DD_HH-MM-SS.log`。
- 解析失败的文章列表 `logs/failed_articles.json`，便于人工复核。

**定时任务配置（示例）**：
用户可在 Windows 使用"任务计划程序"，在 macOS/Linux 使用 `cron`，按月执行：
```bash
# crontab 示例：每月 5 号凌晨 2 点执行增量更新
0 2 5 * * cd /path/to/project && python update_data.py --mode incremental >> logs/cron.log 2>&1
```

## 8. 风险与应对

| 风险 | 影响 | 应对措施 |
|-----|------|---------|
| 北极星网站结构变更导致爬取失败 | 高 | 脚本增加异常捕获与邮件/日志告警；保留本地缓存数据，确保历史数据不丢失 |
| LLM 解析图片图表准确率不足 | 中 | 建立人工复核机制（`failed_articles.json`）；对关键数据采用多模型投票 |
| 部分省份电价数据缺失 | 中 | 在 UI 上以"数据缺失"灰色态展示，不强制补全；允许用户上传补充数据 |
| 地图数据领土合规性 | 中 | 使用 Natural Earth 数据时，手动校验台湾、藏南、南海诸岛边界完整性 |

### 9.2 数据表结构

**`province_capacity`（装机量表）**

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | INTEGER PK | 自增主键 |
| province_code | VARCHAR(6) | 省份编码 |
| year | INTEGER | 年份 |
| month | INTEGER | 月份（1-12，0 表示年度汇总） |
| thermal_mw | INTEGER | 火电装机 MW |
| hydro_mw | INTEGER | 水电装机 MW |
| wind_mw | INTEGER | 风电装机 MW |
| pv_mw | INTEGER | 光伏装机 MW |
| nuclear_mw | INTEGER | 核电装机 MW |
| other_mw | INTEGER | 其它装机 MW |
| total_mw | INTEGER | 总装机 MW |
| source_url | TEXT | 数据来源 URL |
| updated_at | TIMESTAMP | 更新时间 |

**`province_price`（电价表）**

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | INTEGER PK | 自增主键 |
| province_code | VARCHAR(6) | 省份编码 |
| year | INTEGER | 年份 |
| month | INTEGER | 月份 |
| spot_avg_yuan_mwh | DECIMAL(10,2) | 现货均价 元/MWh |
| medium_long_avg_yuan_mwh | DECIMAL(10,2) | 中长期均价 元/MWh |
| spot_high_yuan_mwh | DECIMAL(10,2) | 现货最高价 元/MWh |
| spot_low_yuan_mwh | DECIMAL(10,2) | 现货最低价 元/MWh |
| source_url | TEXT | 数据来源 URL |
| updated_at | TIMESTAMP | 更新时间 |

**`inter_province_trade`（省间交易表）**

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | INTEGER PK | 自增主键 |
| from_province_code | VARCHAR(6) | 送端省份编码 |
| to_province_code | VARCHAR(6) | 受端省份编码 |
| year | INTEGER | 年份 |
| month | INTEGER | 月份 |
| avg_price_yuan_mwh | DECIMAL(10,2) | 交易均价 元/MWh |
| trade_volume_mwh | BIGINT | 交易电量 MWh |
| channel_id | VARCHAR(50) | 关联输电通道 ID（如有） |
| source_url | TEXT | 数据来源 URL |
| updated_at | TIMESTAMP | 更新时间 |

> **注**：`trade_volume_mwh` 使用 `BIGINT` 类型，单条记录最大可存储约 9×10¹⁸ MWh，足以覆盖任何月度省间交易电量规模。前端展示时自动转换为 GWh（除以 1,000）或 TWh（除以 1,000,000）。
