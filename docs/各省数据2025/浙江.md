## 一、2025年底装机量（分电源类型）

截至2025年底，浙江省内电源总装机规模达到 **177.16 GW**（17716万千瓦），清洁电源装机首次突破1亿千瓦，占比达56.8%。光伏超越煤电成为第一大装机电源，风光合计装机达71 GW。

| 电源类型 | 装机容量 | 单位 | 备注/数据来源 |
|:---|:---:|:---:|:---|
| **火电** | ~79.75 | GW | 含煤电、气电；全国火电装机前十省份中浙江位列第7，约7975万千瓦 |
| **水电** | ~17.20 | GW | 含常规水电与抽水蓄能；全国水电装机前十省份中浙江位列第7，约1720万千瓦 |
| **核电** | ~9.17 | GW | 2024年底约916.6万千瓦，2025年无新增投产 |
| **风电** | — | GW | 2025年末风光合计71 GW，光伏为第一大电源；2024年底风电约649万千瓦 |
| **光伏** | >59.47 | GW | 2025年6月底已达59.47 GW，全年持续新增 |
| **抽水蓄能** | >10 | GW | “十四五”期间累计建成超1000万千瓦 |
| **新型储能** | — | GW | 具体数值未在公开报告中单列 |
| **省内电源总装机** | **177.16** | **GW** |  |

> **数据来源**：国网浙江省电力有限公司、国家能源局2025年全国电力统计数据、浙江省经济信息中心

## 五、数据局限性说明

| 缺失数据项 | 说明 | 建议获取渠道 |
|:---|:---|:---|
| **逐月用电量（3-8月、10-12月）** | 官方通常公布累计值，单月值需推算或等待《浙江统计年鉴》 | 浙江省统计局、国网浙江电力月度发布 |
| **逐月发电量（分电源）** | 仅获取到1-2月、1-11月、全年累计值 | 中电联月度报告、浙江省能源局 |
| **逐月中长期交易均价** | 目前仅年度均价412.39元/MWh及全年净交易均价390.69元/MWh有公开数据 | 浙江电力交易中心月度结算公告 |
| **逐月现货市场均价（8-12月）** | 仅1-7月有区间值239-319元/MWh | 浙江电力现货市场运营报告 |
| **逐月跨省受电量、送电量** | 全国层面有跨区/跨省总量，但浙江分月明细未公开 | 国网浙江电力调度中心、国家能源局华东监管局 |

如需进一步细化，建议直接查阅**浙江电力交易中心**（https://zjpx.com.cn）的月度市场运营报告，或**浙江省统计局**年度《浙江统计年鉴》获取最终核定数据。
