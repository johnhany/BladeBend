## 数据缺失说明

| 缺失数据 | 原因 |
|---------|------|
| 1-3月、12月跨省输送月度明细 | 黑龙江电力交易中心未在公开渠道披露 |
| 每月全社会用电量明细 | 仅检索到上半年总计数据 |
| 1-7月现货月度均价 | 黑龙江现货市场8月1日才启动连续结算试运行 |
| 每月跨省输送具体受方省份明细 | 官方仅披露联络线总电量，未公开分省明细 |
| 火电/水电分项装机 | 官方仅披露新能源装机，火电水电为推算值 |

如需更详细的原始数据，建议直接联系**黑龙江电力交易中心**或查阅**北京电力交易中心**的月度省间交易报告。
