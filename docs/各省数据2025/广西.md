**关键说明：**
- 2025年4月15日，广西全区发电装机规模正式突破1亿千瓦（100,004 MW），成为我国西部首个包含水、火、核、风、光等多种电源的省（区）级电网 
- 截至2025年8月底，全区电源总装机容量达1.12亿千瓦，清洁能源占比超七成；非化石能源发电装机容量达7883.5万千瓦，装机比重达70.3% 
- 截至2025年12月底，广西电力市场注册发电企业装机容量7863.53万千瓦（仅含市场注册机组）

## 数据缺失总结

| 需求项目 | 缺失情况 | 原因 |
|---------|---------|------|
| 2025年每月全社会用电量 | **完整月度数据缺失** | 广西统计局/电网未公开分月全社会用电量明细 |
| 2025年8-10月发电量 | **单月数据缺失** | 仅检索到1-7月、11-12月及全年累计 |
| 2025年每月中长期交易均价 | **1-11月逐月数据缺失** | 交易中心仅披露半年/全年累计及部分月份 |
| 2025年每月现货均价 | **仅5-6月试运行数据** | 广西现货市场2025年未进入连续结算试运行，仅开展短周期测试 |
| 2025年每月跨省输送电量 | **月度明细缺失** | 西电东送数据按南网整体披露，广西分月送出明细未公开 |

如需进一步获取缺失的月度数据，建议直接联系**广西电力交易中心**（https://www.gxtdl.com）或**南方电网广西电网公司**调取内部运行月报。
